Q: 如何在 iPhone 上启用 TypePrompt 键盘？
答：请在安装 App 后，前往 iPhone 的系统“设置 (Settings) -> 通用 -> 键盘 -> 键盘 -> 添加新键盘”，选择并添加 `TypePrompt`。
Q: 键盘必须开启“允许完全访问”权限吗？
答：不是必须的。为了保障您的隐私安全，TypePrompt 支持在**关闭**完全访问权限时独立以“体验模式”运行，100% 保护输入隐私；如果您需要读取在主 App 中自定义保存的卡片，则需要在“键盘”设置里启用“允许完全访问”。
Q: 购买了 Pro 会员但键盘没有解锁，该怎么办？
答：请确保开启了“允许完全访问”权限，键盘方可与主 App 进行数据库同步。如果状态仍未刷新，请回到主 App，在“我的”页面点击“恢复购买”按钮。

Q: How do I enable the TypePrompt keyboard on my iPhone?
A: Go to your iPhone Settings -> General -> Keyboard -> Keyboards -> Add New Keyboard, and choose `TypePrompt`.
Q: Is "Allow Full Access" required for the keyboard?
A: No. To protect your privacy, TypePrompt runs in a local "Read-Only Mode" without full access. If you need to access your custom prompts saved in the host App, you must enable "Allow Full Access" in Settings.
Q: I bought Pro but the keyboard features are still locked?
A: Ensure "Allow Full Access" is enabled so the keyboard can sync data. If the status doesn't update, open the host App and tap "Restore Purchases" in the settings.

Q: iPhoneでTypePromptキーボードを有効にする方法は？
A: iPhoneの 設定 -> 一般 -> キーボード -> キーボード -> 新しいキーボードを追加 から、`TypePrompt`を選択して追加してください。
Q: キーボードには「フルアクセスを許可」が必要ですか？
A: 必須ではありません。プライバシー保護のため、フルアクセスなしでもローカルの体験モードとして動作します。ホストアプリで保存したカスタムプロンプトを読み込むには、設定で「フルアクセスを許可」をオンにする必要があります。
Q: Pro会員を購入したのに、キーボードがロックされたままです。
A: キーボードがデータベースと同期できるよう、「フルアクセスを許可」がオンになっていることを確認してください。それでも同期されない場合は、ホストアプリに戻り、「マイページ」の「購入の復元」をタップしてください。

¿Cómo activo el teclado TypePrompt en mi iPhone?
Respuesta: Vaya a Ajustes -> General -> Teclado -> Teclados -> Añadir nuevo teclado y elija `TypePrompt`.
¿Es obligatorio activar el "Acceso total" para el teclado?
Respuesta: No. Para proteger su privacidad, el teclado funciona localmente sin acceso total. Si necesita cargar los prompts personalizados que ha guardado en la aplicación principal, debe activar el "Acceso total" en Ajustes.
Compré la Suscripción Pro pero las funciones siguen bloqueadas
Respuesta: Asegúrese de activar el "Acceso total" para sincronizar la base de datos local. Si sigue sin funcionar, vaya a la aplicación principal y pulse en "Restaurar compras".

Comment activer le clavier TypePrompt sur mon iPhone ?
Réponse : Allez dans Réglages -> Général -> Clavier -> Claviers -> Ajouter un clavier, puis sélectionnez `TypePrompt`.
L'activation de l'accès complet est-elle obligatoire ?
Réponse : Non. Pour votre confidentialité, le clavier fonctionne sans accès complet. Si vous souhaitez charger vos prompts personnalisés, vous devez activer l'accès complet dans les réglages du clavier.
J'ai acheté l'abonnement Pro mais le clavier est toujours bloqué ?
Réponse : Vérifiez que l'accès complet est bien activé. Si le statut n'est pas mis à jour, ouvrez l'application et appuyez sur "Restaurer les achats".

Wie aktiviere ich die TypePrompt-Tastatur auf meinem iPhone?
Antwort: Gehen Sie auf Ihrem iPhone zu Einstellungen -> Allgemein -> Tastatur -> Tastaturen -> Tastatur hinzufügen und wählen Sie `TypePrompt`.
Ist „Vollzugriff erlauben“ für die Tastatur erforderlich?
Antwort: Nein. Zum Schutz Ihrer Privatsphäre funktioniert die Tastatur lokal ohne Vollzugriff. Um auf Ihre eigenen Vorlagen aus der App zugreifen zu können, müssen Sie „Vollzugriff erlauben“ aktivieren.
Ich habe Pro gekauft, aber die Tastatur ist gesperrt?
Antwort: Stellen Sie sicher, dass „Vollzugriff erlauben“ aktiviert ist. Falls der Status nicht aktualisiert wird, öffnen Sie die Haupt-App und tippen Sie auf „Käufe wiederherstellen“.
